# ForgePilot Stitch UI Design V1

本目录保存制造领航 ForgePilot 的第一版 Stitch 界面设计交付物。

## 文件

- `ForgePilot-Stitch-UI-Design-v1.zip`：从 Google Stitch 导出的完整设计包。

## 内容

压缩包包含 9 组页面的 HTML 与 PNG 预览，以及一份 `DESIGN.md` 设计说明。该版本用于确认 ForgePilot 的品牌基调、页面结构、核心业务操作和后续 React 前端实现方向。

## 使用约定

- 本文件属于 A 任务包“产品设计与 Web 前端”。
- 后续修改应继续从 `task/issue-2-stitch-design-system` 分支提交 Pull Request。
- Stitch 导出代码仅作为设计参考，进入正式前端前需要完成组件拆分、可访问性检查、响应式适配和接口接入。
- 演示数据不得替换为真实企业敏感信息。
