# 视频分镜脚本

## 项目信息

- 名称：制造领航 ForgePilot 校赛演示
- 类型：真实页面与代码操作录屏，普通话讲解
- 总时长：7 分钟，1920×1080 或更高，MP4
- 受众：第九届传智杯 AI WEB 网页开发挑战赛评审
- 目标：用同一版仓库、技术 PDF 和网页证明功能可复现，并清楚标明虚构数据与 mock 模型边界

## 创作策略

核心路线是“设备事实 → 告警 → 诊断证据 → 人工确认 → 工单 → 审计”。全程录制集成分支启动后的 API 模式页面；显示浏览器地址栏或在开头口述版本号。录制前重置虚构种子数据，保证编号和状态可重复。镜头使用静态屏幕录制与局部放大，不使用虚构工厂画面冒充真实设备。

## 角色与场景设定

- 讲解人：林同学配普通话旁白；画面主体为 ForgePilot 页面、终端与 GitHub 仓库。
- 演示账号：`demo@example.com`，仅用于本地虚构数据；密码不在成片显示。
- 演示设备：`AC-07` 空压机，指标与说明书均为虚构样例。

## 剪辑与视听建议

- 节奏：录屏实速为主；网络等待超过 3 秒可剪掉，但保留保存后的刷新与结果，避免把失败剪成成功。
- 画面：固定 16:9、系统缩放 100%，表单输入采用虚构姓名和设备；账号密码与任何密钥打码。
- 声音：普通话清晰、音量一致，无背景音乐或仅用低音量无版权问题的素材。

## 待确认事项

- GitHub 最终提交号、合并后的页面版本与技术 PDF 要一致；目前远端 PR 尚未合并。
