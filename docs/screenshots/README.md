# 界面截图

所有截图来自线上演示 <https://forgepilot.xiaotianworks.cn/>，账号 `demo@example.com` / `ForgePilot123!`，数据为虚构演示数据。

| 文件 | 页面 | 说明 |
|---|---|---|
| `01-login.png` | 登录 | 真实账号登录，支持组织代码 |
| `02-overview.png` | 维护总览 | 设备健康度、未关闭告警、未完成工单、最近诊断 |
| `03-devices.png` | 设备中心 | 设备档案、专属测点、趋势与维修历史 |
| `04-alerts.png` | 告警中心 | 页签计数、组合筛选、指派与处理 |
| `05-diagnosis.png` | 诊断工作台 | 真实 DeepSeek 诊断、事实/推断/待验证分区、证据阅读器、Token 用量 |
| `06-knowledge.png` | 知识证据 | 说明书上传、解析预览、检索与引用 |
| `07-work-orders.png` | 维护工单 | 列表/看板/日历、指派、状态流转与验收 |
| `08-people.png` | 人员与权限 | 岗位、班组、停用与工单转派 |
| `09-audit.png` | 审计记录 | 操作人、时间、对象与前后变更 |

截图使用 1600×1000 视口，诊断页为整页截图。
